MODULE 9 · MIDTERM EXAMINATION

Midterm Exam

The midterm is the Python Business Process Exam: a 75-minute, handwritten, in-class exam worth 100 points. Three questions ask you to turn a business process into Python using conditionals, loops, and functions. No laptops, no phones, no AI tools. One handwritten page of notes is allowed.

This module: Exam Guide Study Guide
What this page tells you: exactly what's on the exam, exactly what isn't, what materials you may bring, and how to prepare. The Study Guide has the worked examples and the practice problems.

Format

  • Date: Module 9, regular class meeting
  • Duration: 75 minutes
  • Format: Three handwritten questions, 100 points total. You write all Python code by hand.
  • Materials allowed: One handwritten page of notes, using one side only of a standard 8.5×11 sheet of printer paper, prepared by you. Pen or pencil.
  • Materials NOT allowed: Laptop, phone, smartwatch, textbook, prior labs, AI tools of any kind
  • Weight: 20% of final grade

What's on it

The exam covers all course material from Module 1 through Module 8. Every question gives you a business process in plain English and asks you to write the Python that carries it out. The scenarios will be new. The patterns are the ones you practiced in Modules 5, 6, and 7.

  1. Question 1 · Conditionals and business rules · 30 points. Translate a set of tiered business rules into Python and calculate the result.
  2. Question 2 · Loops with conditionals · 35 points. Process a list with a loop to find totals, counts, and a highest value.
  3. Question 3 · Functions, loops, and conditionals together · 35 points. Write a function, call it inside a loop, and explain your design in a sentence or two.

How it is graded

Because notes are allowed, grading rewards logic over memorized syntax. Copying valid Python from your notes will not earn full credit by itself. You earn points for showing you can:

  • Translate a written business process into Python logic
  • Choose the right control structure for the job
  • Organize the steps in the correct order
  • Trace how data moves through the program
  • Combine conditionals, loops, and functions in one solution

Minor handwritten syntax slips can still earn partial credit when your intended logic is clear. Your solution must still show that you understand how the program should work.

Loop only

Built-in shortcuts such as sum(), max(), and min() are not accepted. Totals, counts, and highest values must come from your own loop.

Topics covered

All course material from Module 1 through Module 8 is covered. The three questions are built on these modules:

  • Module 5 — Conditionals · if/elif/else chains, tiered rules, boundary wording such as "below" and "or more"
  • Module 6 — Loops · for loops over a list, running totals, counters, finding the highest value
  • Module 7 — Functions · def, parameters, return, calling a function inside a loop

Variables, arithmetic, and comparison operators from Modules 3 and 4 are part of every answer.

What's NOT on it

  • Multiple choice, fill-in-the-blank, or "what does this print" questions
  • pandas, DataFrames, plotting (Unit 4 — not yet covered)
  • Dictionaries or list comprehensions (Unit 3 — not yet covered)
  • File I/O
  • Anything from a Module 9+ topic

How to prepare

  1. Work through the Study Guide. It teaches the three patterns the exam uses, with a bug to find in each one.
  2. Solve its three practice problems by hand. Use paper, a pen, and only your page of notes. They are written in the same three formats as the exam questions.
  3. Trace your answers on paper. Run the given numbers through your code one line at a time and write down each variable's value as it changes. Slow down, be systematic, don't rush past a step.
  4. Re-run your Module 5, 6, and 7 lab code. If your Module 5 lab fails because you forgot how if/elif chains work, find out before the exam.
  5. Write 5 functions from scratch — no looking. Try calculate_tax(price, rate), apply_discount(price, pct), is_positive(n), count_above(nums, threshold), and greet(name). If you can write these cold, Question 3 will feel familiar.
  6. Re-do the Module 5, 6, and 7 quizzes. They're at the bottom of each reading page. They check the concepts; the exam asks you to apply them to a new business scenario.
  7. Read the Unit 1 and Unit 2 cheat sheets. Use them to decide what belongs on your own page.
  8. Prepare YOUR own page of notes. The act of compressing the material onto one side of a single sheet, by hand, is the studying. Do not skip this step.

What makes a good page of notes

Your one page is the most valuable item you'll bring, and you only get one handwritten side, so space is tight. Fill it with patterns and reminders, not finished programs, because the exam uses scenarios you have not seen. Here is what actually earns points:

  • The if/elif/else skeleton — highest tier first, with an else so every variable gets a value.
  • The boundary-word table — "below" is <, "or more" is >=, "more than" is >, "or less" is <=.
  • The loop skeleton — set up before the loop, update inside it, print after it.
  • The three loop patterns — total, count, and highest, each with its set-up line and its update line.
  • Function anatomy — def, parameters, body indent, return. Note: a function without return returns None.
  • A loop that calls a function — store the returned value, then add it to a running total.
  • The print format — print(f"Label: ${value:.2f}").
  • Your own top three mistakes — the ones you made on the practice problems.

Do NOT waste space on things you know cold — variable assignment syntax, print(), the Python logo. Use the space for things that require active recall under pressure.

Practice problems

The Study Guide has three full practice problems, one in each exam format. Do those first. The quick checks below are shorter than exam questions; use them to confirm the building blocks.

QUICK CHECK 1 · Code Trace
What does this code print? Trace it step by step.
total = 0
for i in range(1, 5):
    if i % 2 == 0:
        total += i
print(total)
Answer
6 — i takes values 1, 2, 3, 4. Only 2 and 4 are even. 2 + 4 = 6.
QUICK CHECK 2 · Bug Fix
This function is supposed to return the tax amount. Find and fix the bug.
def calculate_tax(price, rate):
    tax = price * rate
    print(tax)

result = calculate_tax(100, 0.07)
print(result + 100)
Answer
The function uses print(tax) instead of return tax, so it returns None. Fix: replace print(tax) with return tax.
QUICK CHECK 3 · Write a Function
Write a function apply_discount(price, pct) that returns the discounted price. If pct is 0.2, a price of 50 should return 40.0.
Answer
def apply_discount(price, pct):
    return price * (1 - pct)
